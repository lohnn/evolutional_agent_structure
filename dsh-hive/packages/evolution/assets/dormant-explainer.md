### HIVE — asleep in this session

HIVE, explained like Kanban to a non-tech person: picture a work wall that
decides what kind of work deserves its own pair of hands. Those pairs are
**capabilities** — small specialists that appear when a kind of work shows
up, combine when two are doing the same job, and quietly fold away when
nobody needs them anymore. Each carries **energy**: use keeps a capability
sharp, neglect lets it fade until it dissolves. And they keep what they
learn as **dreams** — short memories that can be recalled later, so the
same mistake is never made twice.

Right now, none of that is running. **This session is dormant** — aware
that HIVE exists, with none of its tools loaded. They will not appear until
you run `/awaken`. Dormancy is not an error; most sessions never need the
wall.

There is exactly one move available, and only when it is true: if the work
in front of you would clearly benefit from several specialists running in
parallel, mention it kindly — once — and let the user run `/awaken`. Then
stop. The wall belongs to them, and so does the moment it is worth waking.
